능력치 99 상한은 언제 걸리나

컨디션 화살표, 감독 보너스, 경기 중 일시 가산(요새 +6 등)이 모두 더해진 뒤에 40–99로 자릅니다. 부스터 같은 상한 초과 가산은 그다음에 붙기 때문에 최종값은 99를 넘을 수 있고, 마지막에 120으로 한 번 더 제한합니다.

계산 단계미발동발동

    기본값은 원문 표의 세 번째 줄(기본 93 + 보너스 6, 요새 발동)을 재현한 예시입니다. 실제 경기에서는 다른 배율·디버프도 함께 관여합니다.

    카드 표시 99의 내부 구성미발동요새(+6) 발동
    기본 99 + 상한 초과 09999
    기본 97 + 상한 초과 299101

    카드에 99로 보여도 발동 시 99일지 105일지는 알 수 없습니다. 상한 전 값과 상한 초과 가산을 둘 다 알아야 합니다. 올 인 패스(+6)·올 인 피니싱(+7) 같은 국소 보너스는 이 계산이 끝난 값을 읽은 뒤 따로 더해지므로 이 표와 섞어 보면 안 됩니다.

    감독 숙련도 89: 기술 +3으로 구간을 넘기면 +1 더?

    컨디션 화살표는 오버롤에 따라 폭이 다르다

    포지션 기본 오버롤 60과 95 사이에서 비례 보간하고 소수점은 0 쪽으로 버립니다. 오버롤이 낮을수록 좋은 컨디션의 상승폭이 큽니다. 공격성은 보정 대상이 아니고, GK가 아닌 선수는 골키퍼 능력치 보정을 건너뜁니다.

    능력치 그룹↓ 최악↘ 나쁨→ 보통↗ 좋음↑ 최상

    양 끝점(오버롤 60 / 95): 센스 [−2, −1, 0, 10, 15] / [−5, −3, 0, 2, 3] · 기술 [−3, −2, 0, 6, 11] / [−9, −5, 0, 1, 2] · 피지컬 [−5, −3, 0, 3, 6] / [−12, −8, 0, 1, 2]. 기준 오버롤은 선택형 부스터를 끈 상태의 값이라 스쿼드 화면 오버롤과 다를 수 있습니다.

    ±18 m는 페널티 박스 선이 아니다
